# corp-net: Knowledge Graph of Global Corporate Ownership

🔍 **Tagline**:  
Build a knowledge graph from the OpenCorporates API to explore and analyze cross-border company ownership and director relationships using Neo4j and NetworkX.

---

## 🌍 Project Goal

`corp-net` aims to provide a structured, navigable representation of corporate networks and ownership structures globally, using data from [OpenCorporates](https://opencorporates.com/). This project helps analysts understand beneficial ownership, corporate hierarchy, and cross-border linkages for financial intelligence and supply chain risk analysis.

---

## 🧰 Tech Stack

- **Python**
- **NetworkX** – for in-memory graph analysis
- **Neo4j** – for persistent graph storage and complex queries
- **OpenCorporates API** – as the data source
- **Pandas**, **Requests**, **dotenv**
